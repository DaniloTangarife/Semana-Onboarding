pwd: Sirve para ver la ubicación actual 
cd (/ruta): Para navegar entre carpetas 
cd .. : Para retroceder una carpeta 
mkdir: Sirve para crear una carpeta
touch: Para crear archivos de cualquier extensión (.txt, .md, .tmp)
echo (nombre del archivo): Para escribir texto dentro del archivo seleccionado
">": Se utiliza al final de echo u otros comandos para sobreescribir sobre un texto y reemplazar el que ya existía
">>": Al igual que el anterior, solo que en vez de eliminar el texto ya existente este lo agrega al final
cat: Consultar el contenido de los archivos o concatenar archivos
head: Busca las primeras líneas escritas de un archivo
tail: Busca las últimas líneas del archivo
rmdir: Borrar un directorio, solo elimina solo carpetas vacías
find: Buscar archivos y carpetas
grep: Buscar un texto o palabra en específico dentro de los archivos
grep -ri: Busca la palabra ignorando mayúsculas y minúsculas
