# Semana de Onboarding - RIWI

Repositorio de actividades y retos desarrollados durante la semana de onboarding.

## Estructura del repositorio

### 1. ALGORITMIA
Ejercicios de lógica de programación y resolución de problemas.

### 2. dia2-herramientas
Actividades relacionadas con herramientas de desarrollo.

### 3. LINUX_100_PASOS
Reto práctico de comandos y manejo de la terminal Linux.

### 4. NOVA_TECH
Misión de rescate de archivos, organización de proyectos, manejo de directorios y creación de un reto de búsqueda mediante la terminal.
